# DINKLY FORMAT — the JJ format from 19 Nov 2026

**Status: binding for JJ.** On 19 Nov 2026 Chuby decided that remakes of @dinklygame's reels **completely
replace** every earlier JJ format (long narrated, short, dialogue ads), because the old ones were
"performing worse than ever". Where `docs/RULES.md` or any other doc disagrees, this file wins for JJ.

Source account: https://www.instagram.com/dinklygame/reels/ (DINKLY, ~14.5K followers, 296 posts,
244 reels, 21 reels over 1M views when checked on 19 Nov 2026).

## Non-negotiables (Chuby, 19 Nov 2026)

1. **Remake only their proven winners**, one remake per source reel, highest views first.
2. **Exact video length of the source reel**, to the frame (30 fps, so within 1/30 s). The builders exit
   non-zero if the length is off.
3. **Exact hashtags of the source reel** (same 5, same order). Never add or swap.
4. **Keep the JJ puppies** (boy: tan, brown ears, eye patch, blue bandana; girl: cream, tan ears, pink bow),
   but drawn in the round "chibi" style below. Change style and content to match Dinkly.
5. **Video is silent.** The song is added in the Instagram/TikTok app when posting (the source reel's
   exact song). Two sources use "original audio": open the source reel → Use audio.
6. **2 videos a day**, 10:00 and 18:00 UK. Posted manually from the phone (the in-app song can't be added
   via Metricool).
7. Text size and font must match theirs — Chuby checks this closely ("we cannot afford to lose").

## Caption structure (every JJ video)

```
<one short lowercase line + 1 emoji>            (same idea as the source caption, own wording)
<comment driver — varies every post>             (no DM needed; see list below)
—
btw, we've been making something for you and your person. it's called CoupleIn, a couples app for a little more time together. if you'd like to check it out, the link's in our bio 💛

<the source reel's exact 5 hashtags>
```

- The CoupleIn line is Dinkly's own plug ("btw, we've been making something… Better With You, a couples
  card game… comment LOVE") with CoupleIn swapped in. Dinkly used it on ~1 in 5 posts; Chuby chose to put
  it under **every** video (19 Nov). Watch reach in week 1.
- Dinkly ends with "comment LOVE and we'll DM you". We use **link in bio** because there is no auto-DM
  tool (ManyChat or similar) on JJ yet. Switch to the comment-DM version only once one is set up.
- Comment-driver avenues, rotate them: type-a-word ("type LOVE if…", KIND, YES, ALWAYS, "I KNOW"),
  pick-one ("which panel is you two? 1, 2, 3 or 4"), tag ("tag the one you'd do every Tesco run with"),
  open question ("comment the age you met"), "wrong answers only".
- Never #fyp #foryou #foryoupage #viral #trending #explore (they're never in the sources anyway).

## Build

Setup as `pipeline/README.md`, plus fonts: `cp fonts/*.ttf ~/.fonts/ && fc-cache -f` (Neucha = Dinkly's
lettering, Nunito = bold caps, Itim spare). Inter must be installed for the iOS notification banners.
Chromium: the builders launch `/usr/bin/google-chrome`; change `executable_path` if your box differs.

- **Note / bold / comic / stacked / montage:** `python3 make_note.py <spec> preview` (contact sheet in
  `work/<spec>/sheet.png`), then `python3 make_note.py <spec>` → `out/<spec>.mp4` + `.qa.json`.
  Spec: `TARGET` (exact source seconds), `STYLE` ('soft' | 'bold' | 'caps' | 'dark'), `BEATS` =
  `(text, draw_js, seconds, opts)`; the last beat's seconds is ignored (gets the remainder).
  opts: `style`, `size`, `col`, `y`, `raw` (screen coords, no zoom), `notif` (iOS banner, see below).
- **Split / side-by-side:** `python3 make_split.py <spec> [preview]`. Spec: `TARGET`, `CUTS` (panel start
  times from the source), `GRID_AT`, `GRID` (False for side-by-side), `SIDE`, `PANELS` (left/right JS in
  half-panel local coords, origin on the floor).
- Get `CUTS`/beat lengths from the source with the scene-cut scan (seek the `<video>` every 0.1 s, draw to
  a 36×64 canvas, mean pixel diff > 9 = cut). The video element is readable from the reel page.
- Shared code: `specs/_dk.py` (chibi JJ rig + all props), `specs/_dkhalf.py` (split-panel snippets).

### Chibi JJ (replaces the old dog rig for this format)

One round mochi body/head, huge glossy eyes, tiny nose/mouth, blush always on, floppy ears in front,
clean lines (no wobble/boil). `old:1` adds white hair tufts + round glasses (for "at 70/80/90").
`make_note.py` overrides `pup()` with it and pulls pups 8% toward the centre (non-raw beats).

### Lessons from the first build (don't repeat)

- Text was first half Dinkly's size and the wrong face — compare against their frames side by side.
- Pulling pups toward the centre (to enlarge them) made faces hide behind the other pup and props
  (bouquet, tray, blanket). Look at every beat's frame; keep ~300 px between pup centres unless hugging.
- Blankets/quilts must sit below mouths; umbrella poles between the pups, not through a face.
- White text on a light background is unreadable — set `col` dark (Dinkly does the same).
- Phone/app visuals must look like a real iPhone (frosted-glass banner, real app icon) — `notif` does
  this. The CoupleIn icon is still a drawn stand-in heart; swap in the official logo when available.

## CoupleIn pitch variants (unproven)

`dk_pitch_mbr` (Mission, Bond, Resolve) and `dk_pitch_mrc` (Mission, Resolve, Calendar) copy the 14.9M
reel exactly but add an iOS CoupleIn notification on each age beat ("Today's Mission · Day 1" → "Day
21,915", Bond question, Resolve "say back what you heard", Calendar anniversaries) and end on the
twist "Day 1: find each other again". **Dinkly never put the product inside the video** — their pitch was
only in the caption — so treat these as a test against dk_love_you_at, not as the format.
